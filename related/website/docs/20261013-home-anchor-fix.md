# 首頁寬屏定位修正

2026/10/13

手機版切換至桌面版時，首頁的固定區段會重新計算捲動距離。舊實作只在首次載入時校正錨點，重新測量後可能回到頁首，或落在產品區下方。WebKit 也可能在頁面開啟後恢復舊捲動位置。

目前會在版面測量完成後恢復對應區段，並等候字型與固定區段完成同一輪重算。沒有網址錨點時，以畫面中佔比最大的區段保留閱讀位置，避免把上一區露出的少量內容誤判為目前區段。

鍵盤、滑鼠或觸控開始操作時，立即停止校正；捲動尚未停止時，也不會重新取得操作前的位置。使用者繼續閱讀時，不會被網址中殘留的 `#products` 拉回。

## 本地生產版驗證

- Chrome、Firefox、WebKit：78 項定位回歸通過，涵蓋英語、繁中、日語；檢查跨斷點、刷新、返回、延後恢復位置、手動閱讀後調整寬／高，以及縮放後立即使用滾輪或 End 鍵。
- 定位測試寬度：390、768、1100、1101、1440、1920、2435、3440px。
- 11 個主要頁面、三語、三引擎、六尺寸：594 組排版檢查通過，未發現橫向溢出、產品文字疊壓或舊版首頁回退。
- 30 項單元測試、TypeScript、改動檔案的 ESLint 及正式建置通過。
- macOS 原生 Safari：三語定位、刷新、返回及手動閱讀後調整寬／高檢查通過；另通過 7 項章節間距、文字入場及透明人物影片檢查。

這些結果來自 macOS 本地測試；WebKit 引擎測試不等同於所有版本的 Safari 實機驗收。先前 Linux 雲端檢查通過，Windows 與雲端 macOS 的完整任務因超時取消，不能列為全部通過。本次跨系統驗證狀態以 GitHub Actions 執行紀錄為準。會員登入、訂單與裝置服務的接入狀態未因本次排版修正而改變。
