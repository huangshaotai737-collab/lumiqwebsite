## 動效與剩餘事項

檢查包括進入區段的標題動效、順向／反向捲動、背景播放、人物影片切換、离開後停止及頁尾實際繪製。測試等待真正的動畫結束，不以固定延遲截取過渡中的畫面。

本機 Chrome、Firefox 在 1440px 與 3440px 影片區獨占採樣時，未重現持續卡頓或背景閃退；首次首屏仍記錄到孤立初始化停頓。幀間隔只反映當次設備與負載，不能保證所有電腦皆達 60fps。試製的 960px 透明影片沒有顯示穩定改善，因此沒有替換原素材。headed WebKit 沒有按要求改變實際視窗寬度，未用該結果宣稱超寬屏性能通過。

隱藏的手機預覽卡片原本仍保留兩個大尺寸 Canvas，現已移除這項資源浪費。本機回歸與獨立審查通過，但尚未證明它就是雲端 Firefox 超時的唯一原因。

玻璃效果現在於卡片至少 20% 真正進入視野時啟動；螢幕邊緣少量露出及完全隱藏時保留霧面備援，不預先建立大尺寸 Canvas。裝飾 Canvas 不接收鼠標事件，商品操作仍使用原有 DOM 控制。這也移除了異步初始化後向已卸載元素綁定事件的危險路徑。

Windows 前置安裝超過八分鐘，因此總作業時限調至 30 分鐘；單次操作時限維持原值。調整後上一輪 Windows 含 Edge 已完成，並非把未完成測試算為通過。
