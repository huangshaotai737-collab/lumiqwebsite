# 首页产品五卡回退修复（2026-10-14）

## 问题与原因

用户反馈首页产品展示偶尔从五张产品卡片变成三张巨大卡片。

通过在浏览器中禁用 WebGL 复现：正常 3D 场景展示五件作品，但普通 DOM 回退仍沿用旧版三卡构图。两张外围卡片透明度为 0 且被设为 `inert`；1710px 窗口中中央卡片宽约 530px。3D 尚未准备好、产品图片加载失败或 WebGL 上下文丢失时，会露出这套旧布局。

## 修复

- 1200px 及以上、3D 尚未就绪时，普通产品卡片按现有 3D 相机的构图单位排成五张完整可见的卡片；中央突出，四张侧卡较小。
- 服务器首屏在 JavaScript 执行之前也具备五卡初始排布；加载结束或回退不再更换产品数量。
- 所有五张可见卡片均可用鼠标和键盘访问。侧卡首次点击选中，选中卡片点击进入产品详情，原有五产品循环保持。
- 普通卡片文字不随整张卡片缩放，保留至少 16px 字号，支持长英文自然换行。
- 桌面回退隐藏旧进度线，避免覆盖产品图片。正常 WebGL 场景和手机原生轮播布局不变。
- GitHub CI 的 WebGL 回退脚本新增首页五卡、尺寸及可访问性检查。

## 验证记录

- 修复前新增四个回归用例均失败，符合三张可见卡片或卡片越出窗口的实际问题；修复后均通过。
- Chrome 新增七项检查通过：WebGL 不可用、JavaScript 未加载、五产品切换与链接、反复手机/桌面切换、3D 图片加载失败、真实 WebGL 上下文丢失、正常 3D 重建仍显示五件作品。
- Chrome 整体回归 55 项通过；另一个旧快照检查因本轮有意删除回退视口的旧三卡内边距而失败。只排除该桌面回退内边距字段、保留其余原始测量后，重新执行通过，合计覆盖 56 项。未修改历史快照。
- WebKit 10 项通过；三个依赖 Chromium CDP/有效 WebGL 环境的案例明确跳过，未计入通过数。
- 另查繁中、英文、日文 × 1200、1440、1710、1920px × 720、900px 窗口高度，共 24 组回退排版：五卡均可见，未发现文字裁切、越界或小于 16px 的可见文案。
- 扩展后的 CI WebGL 回退脚本在本机 Chrome 运行通过；首页和产品列表在禁用 WebGL 时没有未处理页面错误。
- 生产构建、63 项单元测试、TypeScript、三语言 994 个翻译键检查通过；ESLint 零错误，只有 `ProductsShowcase.tsx:243` 已存在的未使用变量警告。

复现记录、截图及 24 组布局结果保存在工作区外的 `验收资料/产品五卡回退修复-20261014`。检查使用浏览器模拟与真实 WebGL 丢失事件，不代表所有显卡和真机均已实测。未改动产品素材，也未提交真实环境变量或构建输出。
