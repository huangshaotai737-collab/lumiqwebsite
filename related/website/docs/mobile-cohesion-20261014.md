# 手机体验统一与走查（2026-10-14）

本轮按用户最新十张截图调整手机体验。以 `01eacd6` 为修改前版本，延续 `codex/mobile-experience-20261014` 分支；全部保留在本地，未推送或部署。

## 调整结果

- 产品轮播与生活故事视频轮播采用同样的原生横向滚动方式。手机不再拦截横向滚轮，关闭产品卡片的模糊、持续光效和图片滤镜；卡片位置只在初始化、尺寸变化时测量，滚动按动画帧合并，选中项不变时不再反复写入五张卡片的属性。
- 手机产品轮播移除卡片两侧箭头和装饰进度线，下方改为上一项、`01 / 05`、下一项。五件产品、链接、循环切换和跨布局保留选中项均保留。手机触控按钮点击区域为 44px。
- 首页 OLA 介绍、产品章节、生活故事、家庭场景、安全、家庭时刻及候补名单标题统一参照首屏主标题：`clamp(36px, 10vw, 48px)`。正文以 16px 为主，内页介绍正文为 17px，辅助文字至少 14px。重点内容未删除。
- 手机正文和辅助标题加深颜色。产品简介正文为 `#34465d`，其对白色底色的计算对比度超过 7:1；这是指定参考底色的计算，并非所有背景图上的逐像素对比度保证。
- 顶部 Logo 根据可用宽度放大，页尾 Logo 高度从 26px 调整到 42px。最窄窗口仍保留购物车、候补名单与菜单入口。
- 产品首屏与结尾操作区移除手机上的长白条，价格、候补名单和购物车紧凑排布。320px 窗口及较长概念价格说明允许自然换行，不挤压按钮。
- 手机页尾改为两列折叠导航；品牌短句与 Logo 同排，完整品牌说明可展开。产品、公司、法律及社交入口保留。三种语言及各页面的收起高度在 270–304px 范围。

桌面新增外层容器使用 `display: contents`，新计数器、品牌说明折叠入口只在手机显示；以上视觉覆盖均限定在 767px 及以下。桌面、平板的产品轮播交互仍使用原有逻辑。
