# LumiQ 本次修改表｜2026/10/13

| 問題／需求 | 本次修改 | 驗證 |
| --- | --- | --- |
| 手機及平板首頁兩側留白，文字挤在圖片旁 | 移除圖片 600px 最大寬度；768–1100px 將文案放在上方，原始全幅畫面置於下方；手機保持直版素材 | 72 項首屏尺寸／語言／引擎組合通過 |
| 桌面與手機缺少購物車 | 新增透明底 ShoppingCart SVG 圖標，桌面放在語言切換左側；加入側欄、商品數量、移除、瀏覽器保存和三語文案 | 60 項購物車場景通過，保留「登記興趣」，不接付款 |
| 點開購物車時背景畫面橫向偏移 | 保留捲動條占位，避免鎖定捲動時改變內容寬度；側欄另按視窗右邊緣定位，手機不裁切。原動效與捲動鎖定保留 | 本次正式版 108 組跨引擎位置檢查、36 組真實 Safari 檢查及 60 項購物車回歸通過；開啟與關閉後位置不變 |
| Safari 彈層鍵盤操作與焦點返回 | 原生 dialog；Tab 保留在彈層內，Escape／關閉返回觸發按鈕，關閉後解除捲動鎖定 | WebKit、Firefox、Chromium 複測通過 |
| 首次載入時按鈕事件尚未就緒 | 購物車讀取本機資料及互動就緒前禁用按鈕，避免看似可點但尚未響應 | 首頁入口及產品入口複測通過 |
| 隱藏及離屏的玻璃卡片仍占用渲染資源 | 卡片至少 20% 真正進入視野、且具有正尺寸時才建立 Canvas；離屏或手機隱藏時卸載，返回後恢復原材質 | 原測試手機隱藏 Canvas 由 2 個降至 0 個；三引擎 × 三語最後正式版 9 項生命週期測試通過，桌面／手機切換及商品選擇正常 |
| WebKit 出現空目標事件監聽異常 | 裝飾 Canvas 使用不含 connect／handlers 的事件管理器，不向已卸載的元素綁定鼠標監聽；商品操作仍由 DOM 控制 | 新增可見性與事件管理約束 9 項通過，全部單元測試 63 項通過；上一輪雲端 macOS WebKit 297 項無失敗，Firefox 超時另列追蹤 |
| 雲端跨系統測試曾長時間無輸出 | 增加分階段 JSONL 日誌、逐路由保存報告、操作超時及三組中間尺寸；字體使用原生條件等待 | 單元測試通過；新雲端工作結果以 PR 為準，不宣稱已解決所有掛起原因 |
| Windows 安裝與四瀏覽器測試超出總作業時限 | 根據前輪安裝超過八分鐘、999 項無失敗但 Edge 未完成的記錄，把總作業時限由 20 調至 30 分鐘；單次操作超時限制不放寬 | 調整後 Windows 含 Edge 及 Linux 已通過上一輪；最後補丁仍另觸發回歸 |
