# 手机体验调整，2026-10-14

基准：`adb164a9cac7a460a27c8ce7614790145780e880`。本地分支：`codex/mobile-experience-20261014`。本轮不推送 GitHub、不部署服务器。

## 适配范围

浏览器可用宽度不超过 767 CSS px 时启用手机呈现，包含缩窄的电脑浏览器。768–1199px 沿用现有紧凑窗口布局；1200px 以上沿用电脑版。共享文案、产品数据、多语言和原始媒体。

- 首页生活故事：手机改为原生横向滑动卡片，露出下一张的一部分，并显示标题、说明、左右按钮和位置。上下触摸仍滚动网页，不使用自定义手势拦截。一次只挂载当前故事的视频，离开区域、隐藏页面或切换故事时暂停播放。窗口切换保留当前故事，动画进行中切换布局也保持编号与卡片一致。
- 产品总览：手机将五个产品入口排为两列、三行，入口全部可见；位置与左右切换按钮移动到图片上方。手机点击无需等待桌面动画的冷却时间。手机不用该模块的 WebGL 玻璃材质，直接使用现有压缩产品图；桌面材质保持原有逻辑。
- 四项功能：手机改为两列卡片；小于360px时单列。允许长文换行，保留产品功能原文。后续视觉调整将标题定为16px、说明14px。
- 所有新增布局样式限定在手机范围内，原导航目的地、商品链接和电脑端视觉规则保留。按用户后续要求，手机取消所有文字至少16px的限制，改用语义字号层级。

## 后续视觉与交互走查

- 顶部候补按钮使用手机短标签，保留完整可访问名称；窄屏菜单改为图标，桌面仍显示原文。
- 手机字号分为辅助12–13px、按钮13–14px、阅读正文14–15px、卡片标题16–20px、章节标题24px、页面标题28px；首页首屏标题仍使用30–42px的范围。输入框保持16px，购物车数量角标为11px。
- 首页第二屏文字与设备图片改为上下独立区域，只裁掉原图片上方的空白，图片保持原比例。生活场景卡片、产品卡片和影片说明采用更紧凑的间距。
- 产品目录改为两列紧凑卡片；320px窄屏使用图左文右单列。五件产品及其详情链接均保留，次要的品牌邀请和服务说明减少占用。
- 会员预览收紧说明、标签按钮和空状态，取消手机内容区480px的固定最小高度。
- 页脚改为原生折叠分组，产品、公司、法律、社交四组均可展开；768px起恢复原列布局。
- 手机首页第二屏和下半段恢复12px位移、420ms渐入文字动效；减少动态效果时立即显示文字，重新启用动效或切换窗口尺寸时重新连接观察器。桌面保留24px、650ms的文字入场规则及原首屏视差时间线。
- 修复日文320px首页按钮越界及方案页按钮文字重叠；窄屏产品目录允许文字列真正收缩，避免长文被页面裁切。
- 额外走查发现：系统开启减少动态效果时，旧版桌面第二屏把三张卡片塞入17%宽度的列，并与设备重叠。为这个模式补齐静态首二屏排版和原始海报；普通电脑版的时间线、排版与交互不变。
