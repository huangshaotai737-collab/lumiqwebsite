# LumiQ 网站接力说明

## 项目位置

正式网站源码位于 `related/website/`，技术栈为 Next.js 15、React 19、TypeScript 和 next-intl。

## 启动

```bash
cd related/website
npm install
npm run dev
```

本地地址：`http://localhost:3000/en`。

常用检查：

```bash
npm run typecheck
npm run build
```

## 主要目录

- `app/`：页面、全局样式和路由。
- `components/`：首页、产品页和通用组件。
- `messages/`：多语言文案。
- `public/assets/`：网站正式图片、视频、字体。
- `components/ProductDetailTemplate.tsx`：五个产品详情页共用模板。
- `app/product-detail-template.css`：产品详情页排版与入场动画。

## 当前状态

- 正式产品：Ola、Ola Go、Tablet、Print、Nest 15。
- 五个产品详情页已统一大标题、产品展示和 1.2 秒入场动画。
- 首页包含桌面视差视频与独立移动端布局。
- Plans 页面使用单张连续背景，区块之间没有背景接缝。
- 桌面端和移动端均已适配。

## 接手规则

1. 只在 `related/website/` 内继续开发。
2. 正式素材优先使用 `public/assets/` 现有文件，不要覆盖原文件。
3. 不提交 `.env*`、`node_modules/`、`.next/`、测试截图或账号密钥。
4. 修改后至少执行 `npm run typecheck` 和 `npm run build`。
5. Vercel 项目根目录设为 `related/website`，生产分支使用 `main`。
