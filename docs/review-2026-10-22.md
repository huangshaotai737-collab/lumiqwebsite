## 获取代码

```sh
git lfs install
git clone --branch codex/admin-platform-design-20261020 --single-branch https://github.com/huangshaotai737-collab/lumiqwebsite.git
cd lumiqwebsite
git lfs pull
```

使用 Node 22、npm 和 Git LFS。两个应用各自安装依赖，不能把一个应用的 `node_modules` 复制给另一个应用。若使用本次提供的完整 ZIP，图片和视频为真实资源文件，解压即可取得这些素材。

```sh
npm --prefix related/website ci
npm --prefix related/admin ci
npm --prefix related/website run build
npm --prefix related/admin run build
```

官网静态内容可以在未配置数据库时构建。后台登录、内容保存和发布、会员、报名与订单等功能需要独立的本地 Supabase、各应用 `.env.example` 对应配置，以及首管理员初始化；没有公开的默认后台账号。具体步骤见 [后台初始化](admin/bootstrap.md)、[本地运维](admin/operations.md) 和 [部署配置](admin/deployment.md)。仓库不包含现有本机账号、数据库内容、草稿、环境密钥或已登录浏览器状态。

## 建议交给检查人员的重点

- 官网：手机、平板、桌面切换；五个产品轮播；首页视频；三语内容；各产品页；原背景是否完整；导航、表单和页尾。
- 后台：管理员／编辑／运营权限；点选内容后的即时预览；保存、审核、发布与回滚；素材替换；商品配置；会员、候补和订单；会话失效与审计。
- 数据和上线：按部署说明核对迁移基线、环境变量、可信入口、正式邮件、备份恢复及支付材料。公开下单和支付仍遵守现有关闭／未配置策略。

检查源码或构建通过不等同于已完成线上部署。`main` 保留现有生产分支职责，本次审核分支便于独立检查和提出修改意见。
