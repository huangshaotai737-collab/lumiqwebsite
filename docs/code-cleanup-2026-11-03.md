# 2026-11-03 保守代码清理记录

本轮以 `29735505b7ea17c1bf58881cef4bd0a6445e5285` 为对照版本。要求是保持现有显示和功能，只删除能确认失效的代码、合并效果相同的样式。本轮没有部署或覆盖公开网站。

## 审核范围与处理原则

- 盘点官网、后台、共享契约和脚本中的 587 个受 Git 跟踪的源码文件、48 个 CSS 文件；检查模块引用和样式重复情况。未把构建产物、依赖目录和历史测试输出算作业务源码。
- 用 TypeScript 模块解析检查静态导入、重导出、字面量动态导入和 require，并补查源码、内容清单和生成器引用。没有把“没有入站导入”直接等同于可以删除。
- CSS 只合并同一作用域中相邻且声明完全相同的规则；保留选择器、属性值、声明顺序、优先级、媒体条件和样式导入顺序。未跨媒体查询提取规则，未改断点或改用全局工具类。
- 失效产品样式需同时满足：当前运行时源码没有对应类名、实际页面没有匹配元素、规则不包含需要保留的素材地址。混合选择器中含现用样式的规则保留。
