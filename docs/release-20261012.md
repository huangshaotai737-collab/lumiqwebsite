# Website release — 12 October 2026

The source remains in `related/website`. This update is based on client commit `9ad48f7`; it does not replace or rewrite the repository history. The client's current `welcome-home` film, poster, portrait presentation and three-language description are retained.

## Changes

- The five product detail pages and member area use separate slate-grey light-ribbon backgrounds. A single fixed, isolated layer keeps the background stable during forward and reverse scrolling.
- Product detail typography is white, including the large desktop product name. On the member page, only the upper title and eyebrow are white; the introduction and panel content retain their existing colours.
- Product detail heroes size to their content rather than the screen height. Desktop hero-to-story spacing is 128px, following the shared section rhythm, instead of growing to more than 500px on tall displays.
- The current homepage is used at every width. Glass-card copy uses a screen-space DOM projection; titles, images and descriptions remain separated in WebKit.
- Heading periods are replaced with spaces before first paint. Commas, body copy and translation source text are preserved.
- Local fonts, media readiness checks, seek coalescing, opaque film layering and static character fallback improve browser compatibility.
- The member area remains a labelled front-end preview. It has no connected login, purchase, device or submission backend. Local settings and drafts stay in the current browser.

## Verification

The merged release build generated 89 routes successfully. All 30 unit tests passed; the translation check covered 993 keys in three languages.

On macOS, Chromium, Firefox and WebKit passed 594 route/language/viewport layout cases and 180 product hero cases. Viewports range from 320px phones to 3440px ultrawide screens, including short desktop windows. Media and font audits are saved locally in `related/website/qa/release-platform`.

The GitHub workflow in `.github/workflows/browser-platform-audit.yml` covers Windows, Linux and macOS, including Microsoft Edge on Windows. Workflow authorization is now enabled. The first fresh installation exposed missing transitive dependencies in the lock file; it was regenerated without changing existing locked versions. Cross-system results must be checked on the pull request before acceptance. Playwright WebKit is not the native Safari application. Native Safari/iPhone acceptance and real membership/waitlist storage remain separate checks.
