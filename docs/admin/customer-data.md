# 客户资料匿名化与工作台

匿名化仅供当前有效管理员使用。品牌尚未确认保留规则，默认生产按钮、服务入口与直接数据库 RPC 均关闭。`private.customer_privacy_policy` 默认 `enabled=false`、`revision=null`；客户端、员工、service_role 都不能修改。没有环境变量、请求参数或后台设置可以代替品牌确认。未来启用必须先明确保留范围、期限及适用依据，再通过单独审核的数据库所有者迁移写入版本；本次不提供生产启用指令。自动化测试只在本地合成数据中临时设置隔离规则并恢复。

## 处理与恢复

管理员输入客户 UUID，选择固定原因代码并确认范围。`request_customer_anonymization` 在事务内取得团队共用锁 7410404，重新核验管理员，拒绝任何员工目标（包括停用员工），依次锁 Auth、profile，与订单创建锁顺序一致。随后暂停客户访问并创建每客户唯一任务。旧 JWT 立即无法读取个人 profile、订单或创建新订单；直接更新另有当前行触发器，避免等待中的旧快照把地址写回。暂停后不能新增客户或订单内部备注。

服务端取得仅 service_role 可用的5分钟任务租约。数据库每步核验租约、当前执行管理员与已绑定的保留版本；发起人仅作为历史记录保留，另一有效管理员可恢复任务。步骤为：通过正式 Auth 管理 API 禁用账号并读回确认；逐键以 null 清理合并式 metadata，改用不可投递的 UUID 占位邮箱、清空电话，并再次读回；数据库检查实际 Auth 存储后原子清理应用数据、记录审计及完成状态。身份 UUID 不删除。

失败任务保留禁用、联系资料确认两个独立标记和固定失败步骤 `auth_ban`、`auth_contact`、`application`，不保存原始异常、联系资料或自由文本原因。失败不会标记已完成，客户保持暂停。管理员可在会员页按任务/客户 UUID 搜索、翻页、刷新，重新打开页面后仍能查看失败并恢复。并发租约拒绝；中断的 pending 任务在租约过期后可恢复。Auth 步骤重复调用使用同一占位值；完成任务重试只返回原任务。若最后响应丢失，应刷新持久任务状态，不根据网络错误推断未执行。

保留策略被停用或版本变化时，旧任务不能继续删除；需运营人员与数据库维护者复核原范围和新规则后另行审核迁移，不自动更新任务版本。当前账号只支持邮箱身份；关联第三方身份、MFA、无法清理或无法读回确认的认证资料会失败关闭，须人工处理，不能被视为完成。数据库还检查待变更邮箱/电话为空；实测本地 Auth 管理更新会清空待变更邮箱。

## 精确范围

| 数据 | 本次处理 |
| --- | --- |
| profiles | 姓名清空、语言重置 en、收件资料清空，状态 anonymized，保留 UUID |
| Auth | 长期禁用（100年）、邮箱替换 UUID 占位值、电话清空、用户/自定义应用 metadata 逐键移除；仅保留邮箱 provider 和验证标记等结构字段，检查邮箱 identity 数据；不删除身份 |
| customer_orders | 仅清空 shipping_address；订单、原币整数金额、状态、条款版本、幂等键/请求摘要及订单关系保留 |
| order_items / payment_* | 产品与价格快照、数量及所有外键保留；支付仍为 not_configured |
| customer_notes / order_notes | 删除该客户以及其订单的全部内部备注，且禁止暂停/匿名化后再添加 |
| customer_privacy_jobs | 保留对象 UUID、策略版本、固定原因代码、步骤状态、必要操作人/时间与尝试次数；租约不暴露给浏览器 |
| audit_events | 原有不可变审计保留；新增审计只存对象、动作、策略/原因代码或步骤，不记录被清理资料全文 |
| 独立 waitlist 报名 | 无客户身份关联，原同意记录、邮箱及运营记录不在本次客户匿名化范围；如需处理必须另行核验申请及保留规则 |
| 服务商日志、备份、外部导出 | 不在本应用可保证删除范围；须依各自管理和保留流程处理 |

这是一项对指定存储范围的受控清理，不表示所有个人资料已从所有系统删除。UUID、订单与必要审计仍可关联，保留的请求摘要也并非不可关联数据。服务商 Auth 安全日志、历史审计或备份可能继续保存此前资料，本界面不声称其已清除。

## 工作台与权限

工作台从数据库读取实际数量。管理员可见会员、独立候补报名、订单、草稿；运营可见前三项；内容编辑仅见草稿。无权项返回 null 并隐藏。会员统计排除任何员工身份与已匿名化客户；草稿只计 draft 状态；订单含保留/取消记录。近期审计为管理员全部、编辑本人 content./media.、运营本人 customers./waitlist./orders. 中最近10条，仅显示必要对象与动作。读取失败显示不可用，不制造0值。支付未开通，不显示营收或推断付款成功。

本地验证：`npm --prefix related/admin run test:e2e:privacy`；数据库 `customer-privacy.test.sql` 与 `customer-privacy-concurrency.test.sql`。浏览器场景使用真实本地 Auth API 和仅合成账号触发的服务故障，观察失败持久状态、刷新与恢复。并发测试以独立会话实际锁等待作屏障。测试不启用真实支付、发送真实邀请、改动生产或删除不可变历史。
