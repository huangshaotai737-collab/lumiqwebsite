# 圖片分類與草稿管理

素材庫可按首頁、產品總覽及各產品詳情頁選擇圖片。共用背景另列一類。點選縮圖後會顯示目前圖片的大圖，確認位置後即可選擇新檔案。下方素材庫的「用途所在頁面」用來縮小用途選項；選擇「不限用途」時，搜尋範圍仍是整個素材庫。

「刪除素材」會將素材歸檔，停止在新草稿中選用。官網和歷史版本已使用的圖片會保留。需要查看已刪除的素材時，將「素材狀態」改為「已刪除（歸檔）」。

官網內容頁的「最近草稿」列出名稱、修改摘要、版本狀態、建立時間與最後修改時間。舊草稿尚未設定名稱時，會以建立日期顯示名稱；可進入編輯頁重新命名。

每次保存前都需填寫簡短修改說明，例如「調整首頁產品介紹，保留目前圖片」。保存後，草稿名稱、說明及保存時間會一同記錄。編輯頁顯示最近 50 次保存，較早記錄仍保留於資料庫。保存草稿不會直接更新官網，提交審核、預覽和發佈仍沿用既有流程。

## 部署時核對媒體驗證路徑

後台的 Vercel 根目錄為 `related/admin`。建置命令會安裝固定版本的 FFprobe，並檢查上傳完成及發佈路由是否包含執行檔與授權文件。

此部署的執行工作目錄為 `/var/task/related/admin`，Production 的 `MEDIA_FFPROBE_PATH` 應設為 `/var/task/related/admin/vendor/ffprobe`。若仍指向 `/var/task/vendor/ffprobe`，檔案雖已上傳至私有儲存空間，完成校驗時仍會回傳 503。更改環境變數後需重新部署才能生效。

未來變更專案根目錄或部署結構時，需重新核對執行路徑，並實際完成一次私有素材上傳與預覽；只有建置及打包檢查通過，仍不足以確認線上上傳可用。
