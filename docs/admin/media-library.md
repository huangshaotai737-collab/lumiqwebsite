# 素材库搜索与引用

后台 `/media` 对整个素材库执行服务端搜索与筛选，每页最多 25 条，按创建时间和素材 ID 倒序稳定排序。显示符合当前条件的精确总数；没有匹配结果与页码超出结果范围分别提示。搜索按大小写不敏感的字面子串匹配文件名、素材 ID、上传用途键、用途类型或该用途原始素材路径；`%` 与 `_` 没有通配符含义。搜索最长 100 字，页码必须为正整数。用途、素材状态和实际引用状态可以组合筛选，翻页保留条件；归档和上传之后继续刷新当前查询。

“上传用途”仅说明此素材通过校验的目标位置。“实际引用”读取当前草稿快照的 `media` 槽位，以及已提交的不可变发布引用并与对应发布快照核对，不从上传用途或存储副本推测引用。筛选可选草稿引用、当前官网引用、历史发布引用或无引用；同一素材可同时有草稿、当前发布及历史发布引用。“当前官网引用”表示数据库当前发布版本引用此素材；官网已发布内容缓存最长 60 秒。

每条素材显示精确的草稿与发布引用处数、当前官网引用状态，以及最多 5 处草稿和 5 处发布引用。引用超过上限时明确提示未展开，计数仍为全部引用。草稿引用包含草稿 ID、版本、状态、用途及现有编辑页链接；发布引用包含不可变发布 ID、用途和当前/历史标记，当前发布优先展示。此读取不授予编辑完整历史发布快照或回滚权限。草稿引用随保存更新，发布引用保持历史不变；归档不删除引用或副本。

数据库 RPC `list_media_library(text,text,text,text,integer)` 每次校验数据库中的当前有效管理员或内容编辑。运营、普通会员、停用员工、匿名访客和服务凭据均无此读取权限。接口只返回素材展示字段和有限引用元数据，不返回内容快照、用户身份、原件/副本存储路径或签名。私有引用表没有新增直接授权。查询使用当前用户会话，服务凭据仅保留既有私有存储检查用途；预览继续使用原有受员工权限保护、10 分钟签名、`private, no-store` 的服务端读取路径。待校验素材没有预览，上传、校验和归档边界保持现有行为。

新增迁移：`supabase/migrations/20261021235900_media_library_lookup.sql`。回归 SQL 位于 `related/admin/features/media/library-regression.sql`，仅使用独立合成 ID，在事务中验证超过 200 条旧素材可搜索、分页/计数/字面搜索、真实草稿/历史/当前发布引用、详情截断及角色边界，结束回滚。该测试应由统一验证流程使用已确认的本地数据库执行，不需要重置或重新播种现有预览数据。
