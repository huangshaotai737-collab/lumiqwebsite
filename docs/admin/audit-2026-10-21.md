## 逐项修复与证据

### B1：产品图发布来源

原校验只检查 `products.*.image` URL 格式，而发布复制和不可变引用登记只遍历 `snapshot.media`。因此填写任意 `/api/media/<UUID>` 可通过保存，发布时却未建立公开读取凭据。纯校验及回滚 SQL 均实际复现了遗漏。

修复将五个产品的图片属性保留为其原始素材槽的兼容别名。编辑器改用对应素材槽的选择器；别名由初始快照生成并受共享校验、服务端验证凭据及 SQL 双重约束。原不可变历史不重写。新验证策略为 `media-products-v3-20261021`。

当前本地保留的两个草稿、两个发布均为合法原始别名，升级前后保护数据一致。若其他环境已有非原始产品图别名，迁移前必须先核对并制定兼容方案，不能把本地结果外推为任意历史都可直接回滚。

### B2：直接下单配额

实际 SQL 红灯证明可连续建立超过 60 笔新订单。新函数从 `auth.uid()` 推导客户配额主体，在同键订单恢复及商业条款、价格校验之后、创建新订单之前执行数据库配额检查。绿色用例验证第 61 笔被拒绝、订单数保持 60、同键返回原订单、变更请求冲突、过期条款优先及其他客户配额独立。

这是“成功创建新订单”的事务配额。失败事务会回滚计数，不能声称所有失败 SQL 请求都会永久计入。官网原服务层限流继续生效；生产入口的总流量承载能力仍未验收。数据库配额错误映射为 `RATE_LIMITED` 和 HTTP 429；当前订单响应没有返回 `Retry-After` 头，不把该头计入已验证行为。

### B3：导出同源保护

单测红灯复现旧 GET 可调用导出服务。修复后 GET 返回 405，跨站 POST 在进入导出服务前拒绝，合法同源 POST 保留筛选与 CSV 下载流程。既有数据库导出权限、每小时五次配额和审计事务继续存在。本轮没有为了测试而导出真实客户记录或删除原审计。

### N1：密码重设与身份反馈

旧 UI 的条件分支把“没有当前资料”当作“链接失效”，而成功完成后也进入该分支。实际本地 Auth 与浏览器先复现成功与过期说明同时出现，再验证修复后的完成、验证中、临时 503 和恢复状态。

同时检查跨标签页身份切换、账户绑定、迟到读取/保存、原密码与新密码的真实验证及页面返回。旧账户资料不能在身份变化后恢复。测试包含真实返回导航和合成 persisted 事件，没有仪器证明浏览器实际进入 BFCache，不能声称已验收所有 BFCache 行为。

### R1：素材检索与引用

新增窄权限的 `list_media_library` RPC，只允许当前有效管理员/编辑读取安全元数据，不开放私有表、存储路径、客户资料或完整历史快照。全库按文件名、UUID 和用途进行字面搜索，返回精确总数及每页 25 项；区分无结果和超范围空页。

引用从当前草稿的实际槽和不可变发布记录读取，当前发布优先显示，并明示明细截断。40 项回滚 SQL 覆盖 202 个素材、旧素材、筛选、字面 `%/_`、引用计数/截断、当前发布及不同角色拒绝。既有素材选择器本来已有搜索分页，不能把本次库列表改进描述为全站此前完全没有搜索。

此投影限制响应体大小，但精确统计和草稿引用查询仍需要扫描，未做大规模并发性能验收。

### B5：静态桌面重复图片

尺寸检查全部正常后，人工查看真实截图仍发现首页双重产品图。根因是旧 `.lh-hero/.lh-ola` 背景与新增静态 artwork 同时生效。新增浏览器断言先在旧版本失败，再在修复构建上验证三语言、1440/1710 两种宽度、产品图、文本与尺寸切换；具体最终结果见下方追加的交付验证记录。

### F1 与被排除的误报

公开交互第一轮 74 项得到 57 通过、15 条件跳过、2 失败，保留原始失败，不改写为一次全绿。

家庭卡片的一项失败经无滚轮对照证明是测试准备竞争：没有滚轮，页面仍从 scrollY 5066 平滑滚到 5207。测试在 hover 后显式瞬时居中再记录基线，保留精确位置相等和选中卡片断言；桌面/手机两项通过，延迟开场失败回退场景也通过。这不算产品修复，未修改生产滚轮逻辑。

视频轮播的原始测试未改、超时未延长、手机项目未跳过。原始聚焦重复 12 次，10 通过、2 失败，失败均为首次切片计数。独立计时看到点击确实触发，800ms 定时器在约 864ms 后解锁，但后续浏览器命令响应延至约 5.4 秒。该探针不能证明所有失败都在 864ms 解锁，也不能证明真机上不存在卡顿。下一步需在目标真机和目标运行环境采集主线程/GPU/媒体轨迹，再决定减轻同屏视频、背景或 3D 渲染工作，不能靠提前改计数掩盖。

独立后端复核最初怀疑部分页面未解析图片槽；检查真实 `ContentImage` 包装器后撤回，未计入 bug。测试 runner 双 Playwright、SQL 早期引用符号、员工读取缺少必需 id 等测试准备错误均已区分，不能算产品缺陷。
