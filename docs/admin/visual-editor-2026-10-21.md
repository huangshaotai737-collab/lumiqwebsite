# 官网内容可视化编辑器（2026-10-21）

## 使用方式

打开本地后台 `http://127.0.0.1:4270/login`，进入「官网内容」并打开草稿。上方为真正加载官网组件的员工私有预览，下方为选中内容的编辑区域。

1. 在工具栏选择页面、语言和电脑／平板／手机视口。电脑视口在较窄后台中按比例显示，官网自身仍按选定的视口宽度排版。
2. 「点选编辑」模式中点击文字或图片，在下方原有字段控件修改，预览同步显示未保存内容。重复文案会列出候选项，需主动选择，避免改错字段。
3. 「浏览交互」可查看导航、轮播等展示交互；页面与语言跳转仍留在私有预览内。报名、会员资料和订单提交关闭，预览购物车不写入访客的持久购物车。
4. 插图和商品图可点选后通过原素材库替换。「背景与视频素材」快捷区已按要求取消，背景仍不会被网页点选误改。所有原字段、分组、搜索、分页和校验定位保留在「全部内容与更多设置」，字段权限与历史数据不变。
5. 撤销、重做和「恢复已保存值」用于临时修改。切换页面、语言、视口或重载预览会保留后台当前输入；离开含未保存内容的编辑页会提示。

取消背景快捷区这一轮没有变更字段清单、素材用途策略、数据库或保存发布 API。图片替换沿用已接入内容管理的素材范围；已实际点选并替换场景插图及 Ola 商品主图，等待新图成功解码后核对未保存预览，已有草稿和其他数据不变。本轮专项证据位于 `.lumiq-local/content-image-editing-20261021/`。

临时预览不会保存或发布。原来的「保存草稿 → 提交审核 → 管理员发布」流程保持不变；新窗口「预览已保存草稿」只读取已保存版本。

## 保留的边界

- 内容保存、审核、发布、回滚 API、版本冲突恢复和角色权限保持原实现。管理员、内容编辑、运营仍受原服务器与数据库权限控制。
- 本轮没有数据库迁移、清库、发布内容、业务配置变更或支付接入；没有推送 GitHub 或云端部署。
- 普通官网路径没有替换模板。预览使用现有组件和样式；Home、Story、Contact、Print 四个服务器入口的私有客户端副本由脚本机械生成，构建前检查与源文件一致。
- 编辑消息校验配置的精确来源、具体 iframe 窗口和 UUID 通道。临时快照只在内存与受保护的父子页面消息中传递，不放进 URL 或持久存储。嵌入预览使用 no-store 和限定后台来源的 frame-ancestors。
- 切页／切换模式后，预览确认已应用当前版本才开放交互，避免短暂按旧模式处理点击。旧版本确认消息不能解除新一轮同步锁。

## 本轮修复的问题

修复了预览语言切换或点击 SVG 链接图标会离开私有预览、跨页链接丢失目标定位、切页重置设备与操作模式，以及编辑文字触发未变更视频反复加载的问题。最后一次复测发现的快速切页模式时序问题也补充了应用确认机制。

点选后自动显示并聚焦编辑控件；相同文案候选列表限制高度。选中字段与完整清单之间去重控件，避免重复字段 ID。失败重载、服务不可用和版本冲突均保留当前输入。

## 配置与限制

官网部署环境需设置精确的 `ADMIN_ORIGIN`；未配置时仅关闭新的嵌入编辑，原保存字段与独立草稿预览仍保留。后台使用已有 `WEBSITE_ORIGIN`。本地预览启动器设置官网 4211、后台 4270 对应来源。

首次使用时，官网与后台是不同来源，需要在官网独立登录有效员工账号。连接提示中的「打开官网员工登录」会打开登录页；完成后点「重新载入」，当前后台输入会保留。

同日补充修复：断开连接超过八秒会在预览中央显示登录与重试卡片，避免一直显示同步中却把提示留在画面下方。标题由多个文案字段通过换行或不同颜色拼成时，点选识别会检查完整的直接文字节点，保持精确匹配并保留歧义选择；不使用任意子串猜测。已实际验证繁中首页「同一個家，」「各自的生活節奏」可分别修改，未保存输入在官网重新登录并重载预览后保留，且未向业务接口提交数据。补充修复后重新通过两应用测试／lint／构建／类型检查、19 项浏览器回归和 17 项公开页面对比；专项验证覆盖登录恢复、组合标题两段分别点选、无浏览器异常及已有数据一致性。

新增功能不是任意布局搭建器：滚动时序、交互代码和页面结构继续由开发维护；无法点选或不唯一的字段可从完整字段清单编辑。未保存内容刷新整个后台或关闭窗口后不会恢复，因此离开前应保存草稿。

更新对应公开模板后运行 `node related/website/scripts/generate-visual-preview.mjs`，再检查生成差异；构建前的 `--check` 会阻止源与预览模板漂移。真实设备 Safari、生产来源／Cookie 策略和正式部署仍需在目标环境验收。
