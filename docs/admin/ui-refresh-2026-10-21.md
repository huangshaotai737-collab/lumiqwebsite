# 后台 UI 改版与自检（2026-10-21）

本次只调整独立后台的视觉、导航呈现和响应式排版。基准为 `4155c8d`，代码保存在本记录所在本地开发提交，未推送 GitHub、合并 main 或部署线上。

## 视觉方向与范围

以用户提供的 ERP 界面为主参考：深蓝导航、蓝色强调、浅灰工作区、白色卡片及紧凑的信息层级。另参考 [Ant Design 导航规范](https://ant.design/docs/spec/navigation/)、[IBM Carbon 导航外壳](https://www.carbondesignsystem.com/building-blocks/core/components/ui-shell-left-panel/guidelines) 与 [Shopify 表单分区](https://shopify.dev/docs/apps/design/user-experience/forms)、[布局规范](https://shopify.dev/docs/apps/design/layout)。参考设计原则，不引入这些产品的业务或组件依赖。

- 桌面导航按内容、业务、系统分组，使用 SVG 图标，默认展开并保留折叠；详情页的所属菜单保持高亮。
- 工作台统计采用横向卡片，现有真实数量及权限过滤保留；最近操作按时间排列，操作编号仍可展开。快捷入口复用现有目的页面。
- 商品卡片在宽屏分栏，币种、金额、确认状态、开关及每个保存按钮保持完整；手机恢复单栏。
- 素材上传和素材检索在宽屏分区，原上传限制、配套要求、归档、引用详情、搜索和分页均保留。
- 内容编辑、客户、候补名单、订单、团队、设置、审计、登录及邀请页统一标题、表单、表格、按钮和反馈样式。字段长内容仍可换行或使用原表格滚动容器。

没有合并或移除原有独立页面，没有修改数据库、API、认证、业务服务、请求体、金额计算、权限规则、发布/回滚及支付实现；没有新增后台业务功能或更改官网源码。会员详情、隐私任务等原本的页内交互继续保留在原处。

## 本次改善的问题

| 原界面问题 | 本次处理 |
| --- | --- |
| 默认单字导航难辨认、模块层级不明显 | 默认完整标签、图标、分组和当前页高亮；折叠后保留可访问名称 |
| 统计卡片纵向占用很长、数字层级不足 | 桌面四列指标卡，数字突出；窄屏两列，保留全部说明和入口 |
| 商品表单通栏过宽、反复大段留白 | 卡片分栏、字段分组和控件顶边对齐，保存功能保持原样 |
| 素材上传和检索只能上下寻找 | 宽屏左右分区，窄屏上下排列，完整保留限制与引用说明 |
| 各页文字、按钮、边框和间距不统一 | 建立同一套后台样式；必要状态仍有明确文本，不只依赖颜色 |
| 改版初稿几处小字颜色偏浅 | 独立复核后将相应文字统一加深；白底对比度 5.19:1、工作区 4.83:1、表头 4.92:1 |

## 功能保持检查

最终浏览器以同一合成员工、同一数据库，分别打开改版前 4270 与改版后 4282，对全部 14 页的 input/select/textarea/button 逐项比对标签类型、name、id、按钮文字、选项及禁用状态。十四页均相同。该检查不能替代每个业务所有状态的穷尽测试，但可实际发现漏字段、漏按钮、角色操作误放开等回归。

独立代码复核另检查了表单处理器、请求 URL/方法/请求体、错误与成功反馈、pending/saved 状态、权限映射、统计数量过滤和原页面条件。所有服务/API/SQL/官网路径与基准没有差异。变化的交互仅限导航展开/折叠和选择菜单后的手机导航收起。

- 本次后台 UI 复核没有留下已确认的新增业务回归；没有将“无新增发现”说成所有后端绝对零 bug。

- 本轮为本地 Chromium 桌面和手机视口仿真。未实测实体 iOS Safari/Android、Firefox/WebKit，未对大型真实数据量或并发重新作性能认证。
- 本次没有在交付数据库执行完整的可变业务 fixture、reset 或真实支付。发布、退款、隐私清理等业务没有为截图而触发。
