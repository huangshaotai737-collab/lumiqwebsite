本轮已完成独立后台与现有官网的数据整合，并完成逐任务和最终独立复核。代码保留在本地分支 `codex/admin-platform-design-20261020`；原功能提交为 `920d7d6`；2026-10-21 的新一轮走查修复以本记录所在提交为准。本轮没有推送GitHub、合并或部署服务器。

## 入口和账号

- 后台：http://127.0.0.1:4270/login
- 官网繁中：http://127.0.0.1:4211/zh-hant （另有 `/en`、`/ja`）
- 管理员、编辑、运营的本地账号：仓库 `.lumiq-local/preview-credentials.json`。这是本机私有文件，不上传。
- 启动、停止、重启及本地邮件入口见 [operations.md](operations.md)。本地服务依赖本机Docker/进程，不是永久托管链接。

## 目前可以使用

独立中文后台含内容草稿/预览/发布/回滚、素材、员工角色与审计、会员/候补名单、实际商品配置、订单及内部备注。官网三语真实注册/确认邮件/登录/资料/密码/个人订单与后台共用数据。运营能只读查看实际商品配置，写配置和批准商业条款保持管理员权限。复杂动效与响应式规则仍由代码维护。

价格/商品售卖状态和条款等待品牌确认，全局下单初始关闭；支付仅有预留接口，不能收款。隐私策略初始未确认，匿名化不会自动启用。真实支付接入材料见 [支付准备清单](../superpowers/specs/2026-10-20-lumiq-payments-readiness.md)。
