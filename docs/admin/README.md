# LumiQ 控制中台

后台源码位于 `related/admin/`，官网位于 `related/website/`。两站分别安装依赖，共用根目录的合约与数据库迁移。当前审核分支为 `codex/admin-platform-design-20261020`，获取方式、检查结果及待验收范围统一见 [最新检查交接](../review-2026-10-22.md)。

## 运行与账号

使用 Node 22 和后台自己的锁文件执行 `npm ci`。后台登录需要独立配置的 Supabase、环境变量及首管理员；仓库不提供默认账号或已登录状态。

- [本地启动、停止与预览](operations.md)
- [首管理员与员工初始化](bootstrap.md)
- [邮件与身份配置](auth-email-setup.md)
- [部署与环境要求](deployment.md)

预览脚本采用官网 4211、后台 4270 端口。账号和环境配置保存在被 Git 忽略的 `.lumiq-local/`，由当前机器初始化，不随源码下载。

## 当前功能

后台包含内容草稿、网页点选编辑、即时预览、审核发布与回滚、素材、商品与方案、会员、候补名单、订单、团队权限、设置及审计。管理员、编辑、运营遵守现有角色边界；官网三语账户与后台共用数据。

使用说明见 [内容管理](content.md)、[可视化编辑](visual-editor-2026-10-21.md)、[素材](media.md)、[商业配置](commerce.md)、[客户数据](customer-data.md) 和 [支付接入准备](payment-integration.md)。
