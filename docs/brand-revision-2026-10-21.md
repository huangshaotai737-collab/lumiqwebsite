## 没有擅自完成的项目

1. **Orb 实际 UI 素材**：食谱、日历、家务、相框的完整界面图未提供。结构和文字已可用；不绘制假界面冒充真实产品。
2. **Tablet 对照图及旧玩法归属**：缺少普通平板负面对照图；旧 StoryQuest／ReImagined 与新四玩法的产品归属仍需确认。旧数据保留，没有删除设备功能或历史内容。
3. **Ola 定位冲突**：成人／长辈定位与后续儿童、bedtime 文案不一致；white notice 的确切含义也需品牌明确。
4. **证书、政策和计费条件**：未获得 TUV／80% 蓝光证书、完整配送退货规则、生成次数刷新周期和 Print 加购条件；不写成已认证、已生效的承诺。
5. **背景和动画定稿**：未整体替换全站背景。角色动画失败时增加批准的静态素材回退；真实 iPhone／Safari 透明视频表现仍需实机验收。
6. **已有性能风险**：此前走查中记录的视频轮播间歇性性能风险未因这轮内容改稿自动消除；不能把构建成功视为性能验收通过。

## 内容版本与数据保护

- 原始 `initial-snapshot.json`、原始 manifest 和旧字段策略保持原文；新增命名空间以附加策略校验，缺少整组时兼容历史快照，存在整组时完整校验其字段。
- 显式升级器仅替换仍等于原始值的字段；遇到用户自定义值会保留并列出冲突，不在运行时静默覆盖已发布内容。
- 本地从当前发布版创建新草稿，应用 809 项明确的标量替换和新模块，未覆盖原有草稿或发布记录。
- `brand-content-v4-20261021` 与新增迁移配套：只推进内容校验策略并使过期校验回执失效，不修改会员、员工权限、订单、候补名单和媒体业务表。
- 本轮只在本机应用迁移、刷新官网 4211／后台 4270 并发布本地内容版本。未推送 GitHub、未部署云端、未连接远端数据库。

### 复查中修正的问题

- 旧方案字符串中的年付数字是“折算月价”，不能当作年付总额。现在保留旧格式语义，新版使用明确的年总额格式，并有 14 项价格解析回归测试。
- 新旧文案替换后，部分旧编辑入口已不再影响展示。现在筛选活动字段，保留历史字段校验和自定义文案映射，避免后台出现改完无效果的入口。
- 社交网址和 Facebook 标签纳入可编辑字段，不再把已提供的网址写死在展示组件。
- **仍未解决的初始化风险**：普通动效、高频首开与快速切换视口的压力测试捕获 React `#418`。有过连续 60 次无错误及三语／两种动效偏好 6／6 通过的运行，后续加严复查仍偶发复现，不能据此前一轮通过宣称已修复。两种边界隔离实验没有稳定消除问题，均已撤回，保留原有 DOM、服务端内容和加载方式；没有使用客户端空白挂载或警告抑制掩盖问题。专用回归测试保留，作为继续定位的复现入口。

可在已有本地生产预览运行时执行 `npm --prefix related/website run test:e2e:brand`。该检查仅访问本机页面，不启动或重置数据库、不创建业务 fixture。可通过 `LUMIQ_BRAND_QA_ORIGIN` 指向其他 `http://127.0.0.1` 端口。

本轮浏览器证据保存在忽略的本地工作目录，未将浏览器缓存、账号、截图和构建产物提交到代码仓库。
