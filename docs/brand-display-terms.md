# 官网展示术语

本表用于落实品牌修改清单第 65、79、93 行，供英、繁中、日文页面和后台编辑校对使用。

| 对象 | 展示规范 |
| --- | --- |
| 品牌标识、品牌区眉题 | LUMIQ；使用已有官方 Logo |
| 五款产品名 | LumiqTablet、LumiqOla、LumiqOlaGo、LumiqOrb、LumiqPrint；不加入空格 |
| 繁中主行动 | 加入候補名單；不混用登記興趣 |
| 英文主行动 | Join the waitlist；窄屏导航可用既有 Join list 简称 |
| FAQ 正文 | 保留品牌第 149 行最新批准稿的自然语句；不为强制大写再次改写原稿 |
| 历史内部标识 | `nest`、`pal`、SKU、数据库 ID、旧发布快照保留；展示规范不自动改变这些身份 |
| 已确认受众 | LumiqTablet 面向儿童与参与共读的家长；LumiqOla／LumiqOlaGo 面向成人与长辈；不再将受众定位列作待确认 |
| 未定内容 | 认证名称与数值依据、设备功能状态与联动边界、售后及计费规则，等待相应资料；已确认文案不等于硬件能力验收 |

重要说明、正文和功能利益点至少使用 16px，约 1.5–1.65 行高。导航、计数、非关键类型标签可有独立的紧凑尺寸。标题、导言、正文、按钮分层设置，避免全页按同一比例放大。英文保留本地 Manrope，繁中采用按 Unicode 范围加载的本地 Noto Sans TC 字体，保留系统字型回退和 optional 加载方式；日文保持原有字型回退。

Noto Sans TC 子集来源于 [Google Fonts](https://github.com/google/fonts/tree/main/ofl/notosanstc)，SIL OFL 授权原文随字体保存在 `public/assets/fonts/noto-sans-tc/OFL.txt`。页面不依赖外部字体 CDN，浏览器仅请求当前文字需要的子集。

产品页面名称、导航、对照表、替代文字与页尾在常用宽度下检查；用户保存的自定义内容不应在运行时被静默覆盖。新的正式稿通过原 CMS 保存、审核、发布流程更新。
