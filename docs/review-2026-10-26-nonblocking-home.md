# 首页媒体渐进加载修复（2026-10-26）

基线：43ed9e89a267f342a5ba7a95925c1972958edac0。用户要求首页可立即浏览和导航，不能等待整段动画下载。

## 已确认与修复

- 原首屏在视频完整下载为 Blob、解码后才解除整页滚动锁，并将首页各区域设为 inert；延长下载超时无法解决此问题。
- 移除运行时及首屏 HTML/CSS 的滚动锁、整页交互禁用。顶部导航单独阻塞媒体时原本可点击；本次增加真实点击菜单及产品路由的回归验证，不将未复现的导航故障写成已确认根因。
- 视频改为浏览器原生媒体请求，支持 HTTP Range 和边下载边解码；移除首屏对全文件 fetch/Blob 的依赖。
- 视频尚未到达时，沿用原有首尾画面及文案随滚动展示；媒体到达后对齐当前进度，不重设阅读位置。
- 区分尚未下载的远端帧和已缓冲但无法解码的帧。慢网等待可暂时使用原画面，数据到达后恢复动效，不因网络等待永久关闭。
- 保留 CMS 画面配置、减少动态效果偏好、手机静态布局、后续章节按需加载及异常媒体回退。
- 官网后台的生成式预览已同步；未修改订单、会员、权限、支付、数据库及品牌文案。
