# 产品首屏与候补入口复查（2026-10-14）

本次修复用户截图中 ORB 首次进入产品图空白、OLA Go 标题被遮挡，以及候补入口文案不一致。修改保留在本地 `codex/mobile-experience-20261014` 分支，预览端口 4242；未推送或部署。

## 原因与修改

- ORB：在 1710×900、DPR 2 的全新浏览器上下文中，首屏优化图片请求挂起，图片 `naturalWidth` 为 0、`currentSrc` 为空；原始 WebP 可正常加载。三种外观的首屏图直接使用现成的轻量 WebP，避免重复动态转换。原产品素材、外观选择与图片比例保留。
- 产品标题：Barlow Condensed 使用 `font-display: optional`，字体虽已下载，浏览器仍保留备用字体；缩窄再放大才更新，实测 OLA Go 标题宽度改变约 312px。改为提前加载并允许字体下载后替换，同时把产品名称放进左侧文案的正常布局，字号随内容容器变化，允许必要换行。字体延迟或失败都不会把名称压到右侧产品图上。
- 候补入口：繁中统一为「加入候補名單」，包括产品首尾按钮、方案、报名表、购物车和手机顶部。英文、日文对应入口也统一用语；提交中、成功和错误反馈保留各自状态文案。
