# 首页字母加载与背景蒙版

本轮仅恢复 LUMIQ 字母跳动加载画面、调整首页媒体进入条件，并给首页线条大背景增加 20% 浅色蒙版。卡片透明度、样式、排列、交互和底部切换按钮保留原版。

## 加载流程

- 为首页图片、影片封面、开场首尾静帧及各尺寸背景生成 36 张真实 480px 衍生图片；进入前逐张确认解码完成。
- 同时完整下载开场滚动影片和线条背景滚动影片，等待响应体全部接收完成，而不是只等视频元数据或 canplay。
- 正常分辨率图片在加载画面期间并行下载。480 图片及两段完整影片就绪后立即开放首页；每张高清图、视频封面与 CSS 背景解码完成后再替换对应的 480 版本。
- 两个滚动播放器复用已下载的 Blob URL；重试和离开首页时取消旧任务并释放 URL。资源失败时保持加载画面，提供重试。
- 平板开场图片由同一图片组件管理，避免 picture/source 绕过分阶段加载。手机与减弱动效模式也等待指定的两段影片下载完成。

## 验证

生产构建、TypeScript、改动文件 ESLint、36 张图片的尺寸/透明通道/内容校验、三语言 994 项键检查及内容适配清单检查通过。

桌面和 iPhone Chromium 共 30 项浏览器回归通过，覆盖 480 图片阻塞、高清并行下载、完整影片门槛与复用、失败重试、直接进入 #films、平板和视频封面延迟高清时的连续替换。另以流式响应扣留视频最后 4096 字节，确认不提前放行。

卡片组件、卡片 CSS 和全局布局文件与本轮开始时的提交逐字节比对一致。没有发布或修改管理后台、数据库及 CMS 内容。
