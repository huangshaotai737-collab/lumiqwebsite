# 官网可视化内容编辑器

用户已确认对话中的设计并要求实施，保留其他功能。目标是上方真实网页预览、下方点选内容编辑和独立背景设置；临时输入即时反馈，保存、审核、发布仍沿用现有接口和权限。

## 边界
- 仅修改内容编辑体验和有效员工访问的官网预览。不修改数据库、订单金额、员工授权、会员或支付接口。
- 原有字段、媒体选择器、校验定位、冲突副本、保存、提交、管理员发布全部保留。
- 页面/语言/电脑平板手机切换；电脑固定视口等比缩小，手机按真实视口排版。
- 编辑模式点击选中；浏览模式允许轮播和站内导航，阻断提交、结账及其他业务写入。
- 文案匹配有歧义时明确列出候选，禁止猜测覆盖。未能直接点选的字段仍在全部内容中可达。
- 背景/视频素材独立展示，不在画布点击选择。动画和布局结构继续由代码管理。
- 临时快照只存在当前编辑页与受信 iframe 内存；不新增临时数据库草稿，不把快照放入 URL、存储、日志。

## 实现
复用受保护的员工草稿预览路由，增加 editor 通道。官网服务端按配置的 ADMIN_ORIGIN、有效员工角色和草稿权限决定能否加载可视化预览。父子窗口校验精确 origin、source、随机 channel 和消息结构。失效登录显示重新授权入口，不共享密码或扩大草稿公开范围。

预览使用现有官网组件和样式。三个含服务端取数的页面从原源码机械生成仅供预览的客户端入口，构建前检查完全同步，正式页面源码和运行行为不变。其余入口直接复用客户端可导入组件。预览独立按快照提供三语文案、产品、方案及媒体 CSS；不影响普通官网请求。

编辑器状态增加有限撤销/重做历史和恢复已保存值，保存中的编辑锁、版本号及冲突处理保持。画布中的字段候选由现有清单、当前页、语言和展示值/媒体引用交叉确定；共用字段标出影响范围。

## 验收
未保存输入出现在预览但不调用草稿写接口；点选、重复文案候选、语言/页面/设备切换、撤销重做、背景更换、浏览轮播和无业务写入、错误与重登录状态、保存冲突/失败保留输入、编辑与管理员权限、全部原有控件、桌面/手机布局；后台及官网构建、类型、lint、原有测试与私有浏览器测试通过后更新本地预览。
