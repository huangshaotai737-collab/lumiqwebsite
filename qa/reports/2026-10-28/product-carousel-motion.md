# 恢复产品卡片移动与缩放

用户要求：恢复原来立体轮播的平滑移动、缩放手感；延续固定玻璃与按钮上方倒影裁切。

- 每次切换读取卡片当前显示位置，更新最终布局一次，再用 Web Animations API 的 transform 做 650ms 过渡。倒影与卡片共用容器，同步移动与缩放。
- 最外侧循环卡片在另一侧淡入，不横穿中间卡片。
- 连续反向点击从当前动画位置衔接；尺寸变化、减少动态偏好及卸载时清理动画。初始渲染、手机原生滑动、链接与按钮事件保持原有路径。
- 不重新引入 WebGL、实时玻璃折射或持续运行的卡片动画循环。

验证：正式构建通过；Chrome / WebKit 共 16 项浏览器检查通过（58.8秒）。包含 1440×900、2560×640 的位置/宽度中间帧断言、外侧循环不跨中央、快速反向无位置跳变、减少动态效果立即停止、无 JS 首次显示、按钮/键盘/产品链接及手机原生轮播。未修改既有测试断言。

证据：.lumiq-local/mirror-only-20261027/motion-results.json、motion-check.log、motion-evidence/（实际操作录像与暂停在220ms的中间态截图）。本轮恢复运动过渡，不声称完全复刻旧 WebGL 光学效果。
