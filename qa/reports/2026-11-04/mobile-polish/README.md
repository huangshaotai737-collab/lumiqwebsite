- Vitest：33 个文件，241 项通过。
- Chromium 交互套件：26 项中 23 通过、2 失败、1 未执行；后两类详见下方，未删除或放宽旧断言。

## 已存在的测试问题与边界

1. `feature copy has a clear hierarchy…`：产品总览上方四张简介的标题和正文在基线均为 16px，旧测试要求标题严格大于正文。修改前后得到相同结果。按照本轮保持字体字号的要求，没有顺便改字体。详情页字体保留检查另外执行并通过。
2. `resizing during a desktop story transition…`：电脑窗口在故事过渡过程中直接缩到手机宽度，选中的第二张故事卡可见比例为 0.7051；旧测试要求至少 0.8。修改前后均为同一比例，选中序号正确。本轮手机纯高度变化与触摸滚动测试通过。
3. 旧 `desktop and tablet compositions match the preserved version` 用例依赖 `MOBILE_BASELINE_URL` 且包含已移除的历史选择器，本次未运行；本轮另以两个本机生产服务逐页比较五个产品详情页在 768、1440px 的计算样式，结果保存在 `responsive.json`。
4. 上述浏览器与触摸检查为自动化模拟；未声称真实 iPhone/Android 设备测试通过。浏览器地址栏和设备性能仍可由用户手机复核。
5. 本轮首次响应式采集脚本使用了不存在的 `.pd-feature-list` 定位器，导致采集停止；修正为实际 `.pd-feature-row` 后完整采集。该工具定位错误不是应用故障；交付 JSON 来自完整执行。

原始测试结果：`e2e.json`、`e2e-baseline.json`、`webkit-e2e.json`；构建、单测及静态检查输出保存在本目录的 `*-output.txt`。
